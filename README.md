# Oasis Infobyte Data Science Internship Projects

This repository contains my Data Science projects completed as part of the Oasis Infobyte Internship Program.

## Projects

### Task 1: Iris Flower Classification
- Built a Machine Learning model to classify Iris flower species.
- Used Logistic Regression and K-Nearest Neighbors (KNN).

### Task 2: Unemployment Analysis with Python
- Analyzed unemployment trends in India.
- Created visualizations to understand regional and monthly patterns.

### Task 3: Car Price Prediction with Machine Learning
- Developed a Machine Learning model to predict car prices.
- Analyzed car features and their relationship with selling prices.
